Gracias por tu interés en contribuir a este proyecto.

## Cómo contribuir
- Haz un fork del repositorio
- Crea una nueva rama para tus cambios
- Envía un Pull Request con una descripción clara de lo modificado

## Importante
- No se permiten cambios directos a la rama `master`
- Todos los cambios deben enviarse mediante Pull Request
- Los Pull Request requieren revisión y aprobación antes de hacer merge

## Otras recomendaciones...
- Mantén los cambios claros y enfocados
- Prueba tus cambios antes de enviarlos
- Usa mensajes de commit descriptivos

Gracias por apoyar la mejora de este proyecto ❤️
